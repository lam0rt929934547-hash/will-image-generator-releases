# Will Image Generator

Windows 上的 YouTube 缩略图创作工具：AI 生图、参考图编辑、本地水印与调色、批量导出。

本仓库仅用于发布安装包、使用说明和版本记录，不提供开发源码。运行时请使用你自己的 OpenAI 项目 API Key，安装包不附带 Key。

## 下载与安装

- [下载最新版 Windows 64 位安装包](https://github.com/lam0rt929934547-hash/will-image-generator-releases/releases/latest/download/WillImageGenerator-Setup-x64.exe)
- [查看版本说明与全部附件](https://github.com/lam0rt929934547-hash/will-image-generator-releases/releases/latest)
- [下载 SHA-256 校验文件](https://github.com/lam0rt929934547-hash/will-image-generator-releases/releases/latest/download/WillImageGenerator-Setup-x64.exe.sha256.txt)

支持 Windows 10 / 11，64 位 x64。下载 EXE 后双击安装，无需手动解压。安装到当前用户目录，不要求管理员权限。当前安装包未做商业代码签名，系统可能显示未知发布者。

## 开始使用

1. 在「设置」填写自己的 OpenAI API Key，设置原图与无水印导出文件夹。
2. 粘贴完整提示词，选择生成参数并生成。每次可生成 1–3 张。
3. 在创作台选择成品并点击「导出所选」，进入独立导出工作台；也可从历史记录加入图片。
4. 每张图分别选择水印、调色、尺寸、格式和命名。默认按各水印目录分别导出，也可切换到统一文件夹。
5. 使用全部总览或 1／3／9 张对比视图；Ctrl／Shift 多选、空白处框选、拖动标题栏排序，支持撤销。
6. 在「水印设计」创建文字／图片／形状图层，读取本机字体，保存可编辑预设。PNG 旧水印与 WatermarkStudio 配置仍可导入。

「尺寸参数优先」默认开启：按生成尺寸控件提交，原始提示词保留，不再弹出尺寸冲突提醒。提交成功后提示词框自动清空。

生图、DeepSeek 优化请求与更新下载跟随 Windows 系统代理。API 用量、模型权限与额度由 OpenAI 项目控制；本地导入、水印和导出不消耗生图额度。

## 0.2.0 水印设计与多画板导出

Will Image Generator 0.2.0 将水印设计与成品导出升级为独立工作区。

- **水印设计器**：文字、图片、形状图层，本机字体与字体文件导入，局部文字样式、4 重描边、投影、内阴影、内外发光、渐变、混合模式、基础浮雕与线纹效果。支持对齐、缩放、旋转、编组、锁定、撤销和封面底图预览。
- **可编辑水印工程**：保存为水印预设、导出透明 PNG、导入导出 `.willwatermark` 工程。PNG 旧水印保留为只读预设，可调整导出位置与缩放。
- **PSD 导入**：读取普通文字与缓存图层；复杂蒙版、智能对象或不兼容样式默认使用 PSD 自带合成图保留外观，并显示导入报告。可手动切换可编辑图层及原图对照。
- **多画板导出**：全部总览与 1／3／9 张对比视图，Ctrl／Shift 多选、框选、排序、缩放。每图独立设置水印、调色、尺寸与命名，支持新增同图的另一水印版本。
- **高级调色**：整体与自然饱和度分开，RGB／单通道曲线、直方图、色阶、HSL、阴影高光、色彩平衡、黑白、可选颜色、通道混合、照片滤镜、渐变映射、3D `.cube` LUT、颜色替换与参考图颜色匹配。默认只显示基础项。
- **批量输出**：默认按各水印预设目录分别保存，也可统一到指定目录。单项失败不影响其他项目，支持完成当前张后停止。重名自动编号，原图保持不变。
- 延续浅色森林绿／暖金深色主题和定制安装向导，保留既有 Key、历史图片与预设。

兼容边界：这不是 Photoshop 的完整文件编辑器。PSD 字体须在本机存在或自行导入；复杂 PSD 若未保存兼容合成图，不能保证外观。等高线、任意图案纹理、复杂立体样式和局部 HDR 算法不作等价承诺，当前提供可见的基础效果或合成图回退。保存为 Will 工程，不回写 PSD。

安装：下载 `WillImageGenerator-Setup-x64.exe`，退出旧版后覆盖安装。Windows 10／11 x64，无需管理员权限。应用内「检测更新」也可下载安装。安装包未做商业代码签名。

## 0.1.9 DeepSeek 语义优化与流畅交互

- 提示词栏「优化设置」提供独立的 **DeepSeek API Key** 入口，与 OpenAI 生图 Key 分开加密保存。开启「DeepSeek 优化」后根据完整语境改写，一套提示词生成多张只优化一次。
- 默认关闭。DeepSeek 独立计费，不使用 OpenAI 赠送额度；仅发送提示词文字，不上传参考图。原稿、实际提交稿和修改记录保留；失败、取消或需要人工修改时不继续生图，不自动反复重试。
- 采用 `deepseek-flash` 即时模式。旧版本地规则只供参考。优化可能改变画面细节，不保证审核通过或稳定出图。
- 创作台图片可在左侧工作区自由悬浮拖动，实时让位并平滑落下。支持边缘滚动、Esc 取消、撤销排序、Alt + 左右方向键调整。
- 框选逐帧响应；下拉菜单、输入框、复选框和按钮优化圆角、字体与悬停/按压/选中反馈，适配浅色及暖金深色，遵循系统减少动态效果设置。
- 全新原生安装窗口：品牌欢迎页、路径选择、自定义实际进度条、完成和错误提示。覆盖升级及卸载保留用户图片和设置。
- 已验证模拟接口、独立 Key 加密、桌面交互和真实安装/升级/卸载。未使用真实 DeepSeek Key，实际服务请配置自己的 Key 后使用。

## 更新

0.1.4 起，点击软件右上角「检测更新」。默认在检测到新版后自动下载，可关闭此选项。下载完成并校验后点击「退出并安装」，按安装程序完成更新。

优化、生成、保存或导出任务未完成时，软件会阻止安装更新。等待中的队列会暂停；更新后可继续。Key、历史记录、水印设置、原图与导出文件保留。较旧版本首次使用更新功能，需要手动安装一次新版。

## 本机数据

配置与历史记录位于 `%APPDATA%\Will Image Generator`，原图与水印导出目录由用户选择。Key 通过 Windows 加密保存在本机，迁移电脑后需要重新填写。不要把本机配置或 API Key 上传到此仓库。

## 下载校验

发布附件包含 SHA-256 校验文件。PowerShell 中可运行：

```powershell
Get-FileHash -LiteralPath '.\WillImageGenerator-Setup-x64.exe' -Algorithm SHA256
```

将结果与同一版本的校验文件比较。校验不一致时请重新下载，不要继续安装。
